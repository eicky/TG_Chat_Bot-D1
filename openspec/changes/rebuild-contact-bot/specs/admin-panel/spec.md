# admin-panel 增量规格

## Purpose

主管理员通过私聊内联按钮面板管理机器人全部运行配置：验证开关与题目、欢迎语、屏蔽词与自动回复规则、营业状态，无需重新部署。

## ADDED Requirements

### Requirement: 面板入口与权限
`ADMIN_IDS` 中的管理员私聊发送 /start MUST 打开内联按钮控制面板；非管理员的面板回调 MUST 被拒绝且无副作用。

#### Scenario: 管理员打开面板
- **WHEN** 管理员私聊发送 /start
- **THEN** 收到含配置分区按钮的控制面板，而非用户验证流程

#### Scenario: 非管理员回调被拒
- **WHEN** 非管理员构造并点击面板回调
- **THEN** 收到无权限提示，配置无任何变化

### Requirement: 验证配置管理
面板 MUST 支持：验证码模式一键轮换（Cloudflare Turnstile → Google reCAPTCHA → 关闭 → Cloudflare …）、问答验证开关独立切换，以及问答题库管理——列出全部题目、逐条添加（格式 `问题===答案`）、逐条删除；题库为空且问答开关开启时 MUST 显著提示"题库为空，问答验证不生效"。切换与编辑后 MUST 立即重绘面板显示新状态。

#### Scenario: 轮换验证码模式
- **WHEN** 当前模式为 Cloudflare，管理员点击验证码模式按钮
- **THEN** 模式切换为 Google 并立即生效，面板原地刷新显示"Google"

#### Scenario: 切换问答验证
- **WHEN** 管理员点击"问题验证"开关按钮
- **THEN** 配置立即生效，面板原地刷新显示新开关状态

#### Scenario: 添加问答题目
- **WHEN** 管理员在题库页点击"添加"并发送 `1+1=?===2`
- **THEN** 题目入库，题库列表刷新显示该题

#### Scenario: 删除问答题目
- **WHEN** 管理员点击某道题目的删除按钮
- **THEN** 该题移除，其余题目保留，列表刷新

#### Scenario: 空题库警示
- **WHEN** 问答开关为开启且题库为空，管理员查看验证配置页
- **THEN** 面板显示题库为空、问答验证不生效的提示

### Requirement: 转发设置管理
面板 MUST 提供 7 类消息类型开关（转发、媒体、语音、贴纸、链接、频道、文本）的可视化切换：按钮同时显示当前状态（接收/拦截），点击即切换并即时重绘。

#### Scenario: 切换类型开关
- **WHEN** 管理员在转发设置页点击"贴纸"开关按钮
- **THEN** 该类型开关翻转并立即生效，按钮显示新状态

### Requirement: 欢迎语配置
面板 MUST 支持编辑欢迎语：接受纯文本或单条图片/视频/GIF 媒体（附 caption）；欢迎语支持 `{name}` 占位符，展示时替换为用户名称并做 HTML 转义。

#### Scenario: 设置媒体欢迎语
- **WHEN** 管理员在编辑欢迎语时发送一张带 caption 的图片
- **THEN** 保存成功，新用户 /start 时收到该图片及 caption

### Requirement: 列表配置管理
面板 MUST 支持屏蔽关键字与自动回复规则的列出、逐条添加、逐条删除；列表条目以按钮呈现，点击即删除并刷新列表。

#### Scenario: 添加屏蔽词
- **WHEN** 管理员在屏蔽词页点击"添加"并发送新关键词
- **THEN** 关键词入列，列表页刷新显示该条目

#### Scenario: 删除自动回复规则
- **WHEN** 管理员点击某条自动回复规则的删除按钮
- **THEN** 该规则移除，其余规则保留，列表刷新

### Requirement: 黑名单话题手动重置
面板 MUST 提供"重置黑名单话题"操作：清空存储的共享话题标识，系统在下次需要时自动重建新话题。此为共享话题异常状态（误删、误关且重开失败等）的手动兜底。

#### Scenario: 手动重置黑名单话题
- **WHEN** 管理员在面板点击"重置黑名单话题"
- **THEN** 存储的话题标识被清空，下次有用户被屏蔽时自动创建新的黑名单话题

### Requirement: 营业状态管理
面板 MUST 支持营业/休息状态一键切换与忙碌回复语编辑，切换后立即生效。

#### Scenario: 切换为休息
- **WHEN** 管理员点击营业状态切换按钮
- **THEN** 状态变为休息中，面板刷新，用户来消息将收到忙碌提示

### Requirement: 配置输入流程
面板编辑类操作 MUST 采用"点击按钮后，该管理员的下一条私聊消息作为新值"的输入方式：编辑现有配置时 MUST 回显当前值；发送 `/cancel` MUST 取消输入并返回面板；输入完成后配置保存并返回面板。

#### Scenario: 编辑回显当前值
- **WHEN** 管理员点击"编辑忙碌回复语"
- **THEN** 提示消息包含当前回复语内容，等待输入新值

#### Scenario: 取消输入
- **WHEN** 管理员在输入态发送 /cancel
- **THEN** 输入态清除，配置不变，返回主面板

### Requirement: 面板显示真实配置
面板每次渲染 MUST 显示持久化存储中的最新配置值，不得显示任何跨请求缓存的过期状态；配置值中的 HTML 特殊字符 MUST 转义，超长值 MUST 截断显示，网址 MUST 不展开链接预览。

#### Scenario: 多实例下状态一致
- **WHEN** 一次配置修改刚保存成功，管理员从任意入口再次打开面板
- **THEN** 面板显示修改后的值

#### Scenario: 配置值含 HTML 字符
- **WHEN** 问答题目中包含 `<` 或 `>` 字符
- **THEN** 面板正常渲染该值，不因解析失败而无响应
