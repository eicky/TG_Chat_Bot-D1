# keyword-filter 增量规格

## Purpose

对用户消息文本做关键字风控：命中屏蔽词的消息拦截不转发并累计违规，达到阈值自动封禁；同一匹配引擎支持关键词自动回复。

## ADDED Requirements

### Requirement: 屏蔽关键字拦截
用户消息文本（含媒体 caption）命中任一屏蔽关键字时，消息 MUST 不被转发，违规计数加一，并向用户发送含当前计数与阈值的警告。

#### Scenario: 命中屏蔽词
- **WHEN** 屏蔽词列表含"广告"，用户发送包含"广告"的消息
- **THEN** 消息不转发，用户收到"含有违禁词 (1/5)"式警告

### Requirement: 阈值自动封禁
违规计数达到配置阈值时，系统 MUST 自动屏蔽该用户、通知用户已被封禁，并在黑名单话题生成对应卡片。

#### Scenario: 达到阈值封禁
- **WHEN** 阈值为 5，用户第 5 次命中屏蔽词
- **THEN** 用户被标记屏蔽、收到封禁通知，黑名单话题出现该用户卡片，此后消息不再转发

### Requirement: 匹配规则与正则防护
屏蔽词默认按不区分大小写的子串匹配；以 `re:` 前缀声明的条目按正则匹配。正则匹配 MUST 有 ReDoS 防护：模式长度受限、拒绝已知危险形态、被检文本截断至安全长度；非法或被拒绝的正则 MUST 视为不匹配且不报错。

#### Scenario: 子串匹配不区分大小写
- **WHEN** 屏蔽词为"SPAM"，用户发送"spam 消息"
- **THEN** 判定命中

#### Scenario: 正则条目匹配
- **WHEN** 屏蔽词为 `re:加微信\d+`，用户发送"加微信12345"
- **THEN** 判定命中

#### Scenario: 危险正则被拒绝
- **WHEN** 屏蔽词为 `re:(a+)+$` 这类高风险回溯模式
- **THEN** 该条目视为不匹配，其余条目正常生效，系统不超时不崩溃

### Requirement: 关键词自动回复
用户消息命中自动回复规则的关键词时，机器人 MUST 向用户发送该规则配置的回复内容；消息本身仍按正常流程转发。

#### Scenario: 命中自动回复
- **WHEN** 规则为"价格 → 请联系人工客服"，用户发送"价格多少"
- **THEN** 用户收到"请联系人工客服"，消息同时转发到其话题
