# admin-panel 增量规格

## MODIFIED Requirements

### Requirement: 欢迎语配置

面板 MUST 支持编辑欢迎语：接受纯文本或单条图片/视频/GIF 媒体（附 caption）；欢迎语支持 `{name}` 占位符，展示时替换为用户名称。

欢迎语与媒体 caption MUST 按纯文本语义处理：管理员输入的字符 MUST 原样呈现给用户，MUST NOT 被解释为标记语言，因此系统 MUST 在发送前对管理员内容与替换后的用户名称做出适合发送方式的转义，使包含 `<`、`>`、`&` 等字符的内容也能成功送达。

欢迎语发送失败 MUST NOT 向用户暴露内部存储表示：媒体发送失败时 MUST NOT 将存储媒体配置的原始 JSON 作为文本发送给用户。

#### Scenario: 设置媒体欢迎语

- **WHEN** 管理员在编辑欢迎语时发送一张带 caption 的图片
- **THEN** 保存成功，新用户首次触达时收到该图片及 caption

#### Scenario: 含尖括号的纯文本欢迎语可送达

- **WHEN** 管理员把欢迎语保存为包含 `<` 与 `>` 字符的普通文本，随后新用户首次触达
- **THEN** 用户收到该欢迎语，内容按原文显示，发送不因解析失败而丢失

#### Scenario: 媒体发送失败不暴露内部配置

- **WHEN** 已配置媒体欢迎语，但媒体发送因 Telegram 错误失败
- **THEN** 用户不会收到包含媒体配置 JSON 的文本消息

### Requirement: 列表配置管理

面板 MUST 支持屏蔽关键字与自动回复规则的列出、逐条添加、逐条删除；列表条目以按钮呈现，点击即删除并刷新列表。

并发修改 MUST NOT 丢失更新：多个管理员同时添加或删除条目时，每一次被确认为成功的修改都 MUST 反映在最终配置中，MUST NOT 因读取-修改-写回而被其他修改覆盖。删除操作 MUST 定位到管理员当时看到的那个条目；当该条目已被他人删除或列表已变化时，系统 MUST NOT 删除其他条目，并 MUST 向管理员反馈该操作未生效。

#### Scenario: 添加屏蔽词

- **WHEN** 管理员在屏蔽词页点击"添加"并发送新关键词
- **THEN** 关键词入列，列表页刷新显示该条目

#### Scenario: 删除自动回复规则

- **WHEN** 管理员点击某条自动回复规则的删除按钮
- **THEN** 该规则移除，其余规则保留，列表刷新

#### Scenario: 并发添加不丢失

- **WHEN** 两个管理员几乎同时各自添加一个不同的屏蔽关键词，且都收到保存成功反馈
- **THEN** 两个关键词都存在于最终的屏蔽词列表中

#### Scenario: 过期删除不误删他项

- **WHEN** 管理员点击某条目的删除按钮，而该条目在此之前已被另一位管理员删除
- **THEN** 系统不删除列表中的其他条目，并提示该操作未生效

### Requirement: 验证配置管理

面板 MUST 支持：验证码模式一键轮换（Cloudflare Turnstile → Google reCAPTCHA → 关闭 → Cloudflare …）、问答验证开关独立切换，以及问答题库管理——列出全部题目、逐条添加（格式 `问题===答案`）、逐条删除；题库为空且问答开关开启时 MUST 显著提示"题库为空，问答验证不生效"。切换与编辑后 MUST 立即重绘面板显示新状态。

开关切换 MUST 基于当前持久化值原子完成，并发切换 MUST NOT 导致某次被确认的切换丢失。题库的并发修改 MUST 满足与列表配置管理相同的无丢失更新要求。

#### Scenario: 轮换验证码模式

- **WHEN** 当前模式为 Cloudflare，管理员点击验证码模式按钮
- **THEN** 模式切换为 Google 并立即生效，面板原地刷新显示"Google"

#### Scenario: 切换问答验证

- **WHEN** 管理员点击"问题验证"开关按钮
- **THEN** 配置立即生效，面板原地刷新显示新开关状态

#### Scenario: 添加问答题目

- **WHEN** 管理员在题库页点击"添加"并发送 `1+1=?===2`
- **THEN** 题目入库，题库列表刷新显示该题

#### Scenario: 删除问答题目

- **WHEN** 管理员点击某道题目的删除按钮
- **THEN** 该题移除，其余题目保留，列表刷新

#### Scenario: 空题库警示

- **WHEN** 问答开关为开启且题库为空，管理员查看验证配置页
- **THEN** 面板显示题库为空、问答验证不生效的提示

#### Scenario: 并发切换不丢失

- **WHEN** 两个管理员几乎同时切换两个不同的配置开关，且都收到面板刷新反馈
- **THEN** 两个开关的新状态都被持久化
